# Public content check

1. Identify the exact audience, destination, files and approved message.
2. Preserve the user's intended meaning and exact technical artifacts. Remove filler and invented claims.
3. Prefer a real screenshot/reference asset; use text-only when an image adds nothing.
4. Scan text, filenames, links, document metadata, images and archive contents for credentials, account identifiers, personal directories, private endpoints and customer data.
5. Replace private values with labelled placeholders or portable variables; check the resulting instructions still work.
6. Read and inspect the finished artifact, not only the source. Check mobile readability and clipping.
7. Drafting does not authorize publication. Publish only to the specifically approved account/destination.
8. After publication, read back exact text, media and link targets. Keep a concrete URL or ID.

A regex scan is one gate, not proof that everything is safe. Include manual review of context and metadata. Never share a raw live profile export as a starter template.
