# Brief2Ship upstream provenance

The pack includes the unmodified public Brief2Ship Agent Skill, all six files from its references directory, and the repository MIT LICENSE. This is not a copy of the author's private installed skill.

- Source: [five0nit/brief2ship](https://github.com/five0nit/brief2ship/tree/1c6e4c7155c38fa76a8be05f418070d8be32ae1f).
- Exact commit: `1c6e4c7155c38fa76a8be05f418070d8be32ae1f`.
- CLI and skill metadata version: `0.8.0`; the upstream README labels this checkout **unreleased**. No `v0.8.0` tag existed when checked. This is a pinned source snapshot, not a claim of a published v0.8.0 release.
- The previous public Git tag `v0.7.0` is a different version. Do not silently substitute it for this snapshot.
- License: [bundled MIT LICENSE](../skills/brief2ship/LICENSE), preserved byte-for-byte.
- The offline starter installer installs the complete skill, not the CLI. Install the matching CLI using GUIDE.md section 15. The CLI requires Python 3.11 or newer.
- Hermes skills install accepts a raw `SKILL.md` URL, but the inspected URL adapter fetches only directly linked support paths; it does not traverse links inside those references. This pack includes the entire pinned references directory so secondary references are not lost.
- Seven other starter skills are original portable operating procedures. There is no competing bundled repo-first-build skill.
