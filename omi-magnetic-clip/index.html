Inside both ZIPs

Start small. Check the fit.

Each package includes STL print models, editable STEP CAD, Bambu 3MF projects, Python source, previews and a README with assembly and print notes.

  1. Download and unzip one version. Read its README before choosing a plate.
  2. Print the fit test first. Use OMI_PLA_FIT_TEST.3mf, or reslice models/fit_test_plate.stl for your printer.
  3. Check your magnets and threads. The reference magnets are estimated Ø4 × 3 mm; measure yours. Check retention and polarity before trying the full carrier.

Prepared print profile

Bambu A1 mini · 0.4 mm nozzle · PLA · Textured PEI

0.16 mm initial and subsequent layers. Using a different printer? Import the STL files and reslice for that machine.

Print only the models and plates marked for printing. The STEP reference assembly contains reference magnets.

Independent accessory prototype by Michael Costea. Omi mechanical references and included third-party license notices are linked in each package’s README.
